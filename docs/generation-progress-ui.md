# 创建世界页的 AI 生成进度

在原版“创建世界”页面切换到 **AI 进度** 标签，即可查看当前游戏宿主的 AI 创作会话。
这是原页面内的一个原生 Tab，不是另一个 Screen；原版世界设置、创建/取消按钮和
Worldsmith 原生发布上下文保持不变。

## 能看到什么

- 当前会话、草稿 revision、正在处理的请求和生成阶段。
- 计划中的群系、建筑、生物、方块、物品、任务数量，以及实际匹配的已提交定义数。
- 计划目标的名称、用途和状态；可按类别查看并分页、滚动。
- 真实绘图任务的排队、编译、绘制、校验、等待审批、完成或失败状态。
- 修复提示、缺失素材，以及独立的当前创建页原生加载状态。

**总体条显示“已提交目标草稿 X/Y”，不是耗时百分比或可游玩完成率。**
Y 来自 AI 实际提交的 `WorldDesignPlan`，X 按计划中的唯一内容 ID 匹配。
额外添加几个同类定义不会冒充计划目标完成；Boss 已包含在生物目标中，不重复计数。
总体可包含计划中的其它类别（例如地物），不一定等于六张主要类别卡片之和。

建筑按计划中的结构定义/类型计数，不是无限世界里最终出现的建筑实例数量；
组合建筑的部件与绘图任务另行展示，不用任务个数替代建筑总数。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 待提交 | 计划有这个 ID，但尚无对应定义 |
| 已提交 | 目标草稿已存在，仍可能等待其它内容与校验 |
| 待素材 | 已有定义，引用的 PNG 尚未附加到草稿 |
| 需修复 | 当前、可精确定位的错误关联到此目标 |
| 已冻结 | 当前会话记录了冻结包，不等于本页原生加载完成 |

没有设计计划时显示“目标总数尚未确定”，保留已提交数量，不推算百分比。
计划调整后分母随之变化。模型在工具调用之间的思考时间不可观测，不伪造持续上涨的进度。
历史 `finished` 回执也不等于当前创建页已就绪：原生状态必须匹配当前 Screen、包、
registry context、已加载资源和实际选择的 preset。

## 会话和刷新

“自动”跟随本次桥接连接中有明确 begin/resume/修改活动的世界会话，优先于单素材任务。
进度查询本身不抢占选择。也可手选会话；所选会话消失时显示提示，不偷偷换成另一个世界。
重启后仅有历史草稿而无当前活动时，先选择或恢复会话，不把文件名顺序当作最近活动。

“暂停更新”只暂停面板刷新，AI 和绘图任务仍会继续。
窗口大小变化会保留会话选择、暂停、分类与页码，但不会继承过期的原生就绪缓存。
切到其它原生标签时停止不必要的轮询；返回后继续读取最新状态。

界面每约 750ms 通过游戏内只读通道更新。草稿投影在后台执行，render 线程只绘制缓存；
不经 HTTP 自调用，不扫描归档，不在刷新时解码 PNG、编译绘图或修改草稿。
连接 epoch 与选择 token 防止旧请求覆盖新会话。工具并发时显示实际尚未结束的请求，
跟踪容量饱和也不阻断 AI 执行。

## 给 AI 与调试工具

AI 先通过 `worldsmith_begin_world(mode: COMPLETE_WORLD)` 开始任务，再提交
`worldsmith_put_world_design_plan` 中的明确数量、ID、名称与关系。后续正常提交模块、素材和
建筑即可更新面板，无需另发“进度百分比”。

`worldsmith_get_generation_progress_view` 返回与 UI 相同的有界只读数据，可用于核对
会话目录、目标名单和计数。原有 `worldsmith_get_generation_progress` 继续提供详细下一步动作。
两个读取接口都不会开始生成、改变选择或执行来源代码。

UI 显示当前 Minecraft 宿主的会话；其它独立 authoring host 的目录不会自动混入。
要复用独立生成结果，仍可使用 [`.wspack` 资源包](resource-packs.md) 导入。
