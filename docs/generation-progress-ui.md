# 创建世界 · 天工开物

在原版“创建世界”页面切换到 **天工开物** 标签。Worldsmith 的中文名使用“天工开物”，
英文名、命名空间和文件格式保持 Worldsmith。原版设置和创建/取消按钮保持不变。

## 分类卡片

内容区是一个支持滚轮、滚动条与 Page Up / Page Down 的多列卡片列表，按窗口宽度显示
一至三列，不再使用底部“目标：全部类别”筛选和分页按钮。六个主要类别是群系、建筑、
生物、方块、物品和任务；计划中实际使用的地物、地形等类别也会增加对应卡片。

每张卡片包括：
- 原版物品图标、类别名称、`已声明的计划目标数 / 计划总数` 和细进度条。
- 当前已知的内容名称，以及生成中、排队、待生成、已生成、待贴图、待调整等真实状态。
- 对应命名目标的设计 `purpose`，显示为 Prompt；缺少该目标的独立说明时，显示明确标为
  “世界设定”的整个世界 prompt，不虚构逐目标提示。
- 剩余数量；较长提示可悬停查看。

卡片采用固定高度，普通后台刷新不改变布局、标题或滚动位置。不显示“自动同步”跳动
提示，也不在界面重复展示只读观察、原生验证边界等长篇声明。“自动”和“暂停更新”按钮
已移除。顶部从已安装世界包库切换待创建世界，与“世界”页的世界类型保持同一选择；
只有一个包时不显示两侧箭头。当前包有创作会话时跟随其实际进度；导入包或MCP未开启时显示
包内配置计数，不借用另一会话的目标或错误。没有已安装包时仍可查看正在创作的草稿进度。

## 数据口径

计数来自实际 `WorldDesignPlan` 和草稿定义，不是耗时估算。无计划时总数保持未知；额外
的同类内容不冒充指定目标完成。Boss 已计入生物，不额外增加进度单位。建筑数是定义数，
不是地图上的实例数。

“正在生成”只用于已有活动绘图任务。没有可观测执行证据的内容显示待生成或已生成，
不会把模型调用之间的思考时间猜成某个具体群系的执行进度。目标 Prompt 来自计划中的
设计意图，不声称读取到了外部 AI 的隐藏上下文。已有缺失素材或精确修复项会在所属卡片
中显示，计数达标也不替代完整发布检查。

本次创建页的原生就绪状态仍取自匹配 Screen、包、registry、资源和 preset 的回执。
历史 finished 不视为当前就绪。所有这些判断保留在后台，仅将界面用语改得简洁。

## 世界观与审稿

新完整创作增加世界观编写、AI 自检、内容任务书、AI 内容一致性审稿与待修复阶段。
有作者态的当前会话显示设定版本、当前有效 AI 审稿状态与内容审稿计数；“AI 已审核”
不等于用户确认或实玩验证。没有作者态的旧会话、轻量任务和导入包不新增虚构设定。

顶部 **查看世界观** 只打开与当前选中 session／世界包匹配的只读快照，不借用别的
活动会话。长文支持滚轮、滚动条、Page Up/Down、Home/End，Esc／返回回到原创建页。
正文由结构化 WorldBible 确定性生成；64 Ki 字符的显示上限会明确标注截短，完整内容
保存在 session，可用 `worldsmith_get_world_bible(format: markdown)` 读取。
打开后不另起轮询，返回并重新打开可读取新快照；修改仍通过 AI/MCP 更新同一事实源。
浏览不编译几何、不加载 PNG、不触发资源重载或原生激活。
作者态的完整流程与兼容边界见 [世界观驱动创作](world-bible-authoring.md)。

已经有世界包时，卡片和“查看世界观”仍属于当前待创建的包；另有明确标注的
**当前创作稿** 入口，显示本次活动且未完成会话的世界观。悬停说明该创作稿的标题；
点击后后台只读取该会话一次，核对连接、活动归属和修订后再打开单独快照页。
因此新世界尚未写包时也可阅读设定，同时不切换世界类型、不把新稿进度套到旧包卡片。
读到已过期、结束或切换归属的快照时不打开其他会话，提示重新读取。

## 更新与生命周期

仍使用约 750ms 的游戏内只读后台快照，render 仅绘制缓存。取消了把 refreshing 标记作为
呈现状态的做法，避免每轮轮询切换文字。连接 epoch、选择 token 和关闭保护照常保留；
窗口重建保留世界选择与滚动位置，切换到其它标签时停止不必要的轮询。

AI 仍使用 `worldsmith_begin_world`、`worldsmith_put_world_design_plan` 和正常模块/绘图
工具工作，无需另报百分比。`worldsmith_get_generation_progress_view` 返回同一数据源，
`worldsmith_get_generation_progress` 保留详细后续动作。

早期数据链路记录见 [原进度验证记录](examples/complete-world/progress-ui-verification-2026-09-11.json)。
它不是本次新版卡片的画面验收记录；按用户要求，本轮不运行额外测试或切换游戏前台。

## 延迟创建

“已选择，创建时载入”是菜单选择，不是原生激活。只有点击底部创建按钮才准备临时数据包与客户端资源；准备期间锁定选择，成功后自动继续同一次创建。切换卡片、世界类型或进度视图不发起客户端资源重载。原版与其它模组的世界类型继续保留。
